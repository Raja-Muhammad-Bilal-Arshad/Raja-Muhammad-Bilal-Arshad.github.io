FIRST AUTHOR UNDER REVIEW · MCETS, CYPRUS

ARTP & AutoPENT-Bench

A safety-constrained Autonomous Red-Team Planner that turns multi-source reconnaissance from Nmap, BloodHound, and web crawlers into structured, multi-stage attack plans mapped to MITRE ATT&CK. I built a symbolic verification layer with human-in-the-loop gating to keep the system from executing unsafe or out-of-scope actions, then paired it with AutoPENT-Bench, a benchmarking framework that scores autonomous pentesting agents on coverage, path efficiency, stealth, and safety.

  • Modeled exploitation as a deterministic state-transition system across Web, Active Directory, and Cloud environments
  • Ran 30 evaluation trials across DVWA, Juice Shop, an AD simulation, and a cloud emulation environment
  • Reached 0.85 path efficiency in Active Directory attack graphs, resolving optimal privilege-escalation chains to domain dominance
  • Identified exploration drift, over-aggressive probing, and verifier dependency as the main automation risks in agentic pentesting
FIRST AUTHOR UNDER REVIEW · IEEE TDSC

Atomic Re-registration: Post-Quantum Migration for ZK-Rollups

A zero-knowledge proof system for migrating cryptographic state from classical ECDSA-based infrastructure to post-quantum architecture without breaking the chain of trust. The core is a Groth16 zk-SNARK migration circuit compiled to over 4.2 million constraints, benchmarked against current NIST post-quantum standardization requirements.

  • Compiled and verified a 4.2M-constraint Groth16 migration circuit
  • Benchmarked proof generation, verification latency, CPU load, and memory use at scale
  • Built a reproducible framework for testing scalability and correctness of ZK-based cryptographic transitions
  • Incorporated double-blind reviewer feedback across all nine sections through revision
FIRST AUTHOR UNDER REVIEW · IEEE TIFS

Adversarial WiFi CSI Sensing & MeshGuard

A six-node ESP32-S3 mesh built to study how WiFi Channel State Information sensing networks fail under attack. The work introduces novel denial-of-service and data-poisoning attacks against CSI-based sensing, then answers them with MeshGuard, a defense mechanism designed to hold up under the same conditions.

  • Designed and deployed a six-node ESP32-S3 CSI sensing mesh
  • Developed original DoS and data-poisoning attack vectors against sensing accuracy
  • Built and benchmarked the MeshGuard defense against both attack classes
