Cryptography research, informed by how real systems are attacked.

I have built a Groth16 zk-SNARK circuit compiling more than 4.2 million constraints and benchmarked it against NIST PQC requirements. Post-Quantum Migration of Trust Infrastructure: A Survey of PKI, Authentication, and Code Signing, and the Evidence on Deployment

Surveys post-quantum migration approaches and architectural challenges across PKI, authentication protocols and code signing, and reviews published evidence on real-world post-quantum deployment to map open challenges and research directions.

Zero-Knowledge State Migration for Post-Quantum Cryptography

A zero-knowledge proof system that migrates cryptographic state from classical ECDSA infrastructure to post-quantum architectures, with proof generation, verification latency, CPU and memory use benchmarked against NIST PQC standardization requirements in a reproducible framework.

ARTP and AutoPENT-Bench: Autonomous Red-Team Planner for Pentesting

A rule-based autonomous red-team planning engine mapped to MITRE ATT&CK that turns reconnaissance outputs from Nmap, BloodHound and web crawlers into multi-stage attack plans, together with AutoPENT-Bench, a reproducible benchmark for autonomous penetration-testing agents.
